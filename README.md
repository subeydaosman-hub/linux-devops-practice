# Linux DevOps Practice

## Overview

This repository contains hands-on Linux exercises, technical documentation, and OverTheWire Bandit challenges through Level 20.

The focus is on Linux system administration fundamentals, command-line operations, networking, and systematic troubleshooting.

## Technical Skills

- File system navigation and management
- File permissions and ownership
- Process management and system monitoring
- Text processing and output redirection
- File compression and archive extraction
- SSH authentication and secure file transfers
- Network scanning and service identification
- TLS-encrypted communication

Passwords and private SSH keys are excluded from the repository. A `.gitignore` file is used to prevent private key files from being committed.
